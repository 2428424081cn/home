# 起点 · 个人浏览器主页

## 设计方案

参考 Google 新标签页的留白、居中搜索、快捷入口和右下角自定义入口。主页的视觉重心依次为搜索、时间、常用网站。

- **布局**：桌面中间主区最大宽度 720px；搜索框高 64px；快捷入口一排六个。手机主区宽度跟随屏幕，快捷入口排成两行三列。
- **色彩**：默认「晨雾」，暖白底色 `#F8FAF9`、深灰绿文字 `#263A35`、鼠尾草绿点缀 `#688A79`；提供「暖纸」和「夜色」外观。
- **字形**：使用系统字体，中文优先苹方与微软雅黑。时间使用轻字重和等宽数字，日期与提示弱化。
- **细节**：搜索框为细边框胶囊与柔和阴影；快捷图标采用圆角底座；悬停显示浅底；键盘聚焦显示清晰轮廓。
- **入口**：默认 Google、哔哩哔哩、GitHub、ChatGPT、Notion，再加一个添加入口。正式版可由用户替换。

设计稿文件为 `index.html`。可直接用浏览器打开，或运行 `node design/preview-server.cjs` 后访问 `http://127.0.0.1:4173`。

已检查桌面预览（1092 × 887）和手机预览（390 × 844），以及外观面板、浅深色切换和搜索引擎切换。截图保存在同目录：`desktop-light.jpg`、`desktop-dark.jpg`、`mobile-light.jpg`。

## 当前设计稿范围

已提供桌面与手机布局、三种外观、外观面板、搜索引擎选择和 `/` 聚焦效果。时间固定为 10:08，日期固定为 2026 年 10 月 11 日，以便稳定比较布局。网站入口使用真实链接。搜索提交、添加与管理快捷方式、设置保存将在实现阶段接入。

## 首版功能

| 功能 | 交互与结果 |
| --- | --- |
| 时间与日期 | 按设备本地时间更新，日期和问候随时间变化 |
| 搜索 | 输入关键词，按 Enter 或点击箭头跳转到所选引擎；支持 Google、Bing、百度 |
| 网址访问 | 对明确的 `http://`、`https://` 地址直接访问；域名补全为 HTTPS；关键词使用搜索 |
| 快捷方式 | 添加名称与网址，编辑和删除，限制只允许 HTTP/HTTPS 链接 |
| 外观 | 三套主题，支持跟随系统；设置保存在当前浏览器 |
| 键盘 | `/` 聚焦搜索，Enter 提交，Esc 关闭面板，Tab 访问所有操作 |

## 实现计划

1. **页面骨架**：将确认后的视觉稿拆成 `index.html`、`styles.css`、`app.js`，使用原生 HTML/CSS/JavaScript，保持直接打开即可使用。
2. **搜索与时间**：接入真实时间、问候、引擎切换与跳转；用 `URL` 和 `URLSearchParams` 处理网址与关键词，统一地址判断规则。
3. **快捷方式**：增加添加/编辑表单、输入校验、删除确认和空列表状态；以稳定 ID 存储每条记录。
4. **本地设置**：用 `localStorage` 保存主题、引擎与快捷方式；设置版本字段，处理存储失败与损坏数据；提供 JSON 导入导出以便手动迁移。
5. **收尾检查**：验证 390px、768px、1440px 布局、长名称、空搜索、中文和特殊字符、键盘操作、浅深色对比、刷新保留以及存储不可用时的回退。

## 纯前端边界

页面使用本地时间、本地设置与普通网页跳转，首版无需服务器、账号、接口密钥或第三方脚本。页面静态资源可离线加载，搜索和外部网站需要网络。

普通网页无法直接更改浏览器的新标签页设置或读取浏览器书签。用户可把本页设为启动页；替换每个新标签页可后续单独打包为浏览器扩展。当前浏览器的数据保存在该页面的来源下；换浏览器或更换部署地址时，可通过导入导出迁移。

天气、语音搜索、在线壁纸和账号同步保留到后续版本评估，维持首版的简洁度。
